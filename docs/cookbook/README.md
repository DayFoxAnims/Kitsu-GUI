# Cookbook

Short recipes for common tasks in KitsuGui.

This section is under construction. Planned recipes:

- Writing a custom widget
- Creating a right-click menu for any widget
- Making a modal dialog
- Theming overrides without changing the global theme
- Scroll-to-widget in a `KitsuScrollView`
- Loading and switching icon themes at runtime
- Detecting theme changes to refresh widgets
- Handling window resize in user code
- Reducing CPU usage when idle
- Debugging layout problems

If you have a recipe that solved a real problem for you, feel free
to open a pull request adding it here.
